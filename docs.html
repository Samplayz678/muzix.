Introduction & Guide

Welcome to Muzix! We are a next-generation music bot built to provide the highest quality audio experience directly inside your Discord server.

How to Get Started

  • Invite the Bot: Use the invite button on our home page to add Muzix to your server. Make sure it has permissions to View Channels, Send Messages, Connect, and Speak.
  • Commands: Join a voice channel and use our slash commands (e.g., /play [song name]) to start listening immediately.
  • No-Prefix System: Certain users and servers can be granted "no-prefix" status, allowing them to type song names directly without needing a command prefix.

Key Systems

Muzix utilizes advanced Lavalink nodes to ensure 24/7 uptime, lag-free streaming, and automatic node-relocation if a disruption occurs. We also feature an auto-resume function so your music picks right back up where it left off.

Privacy Policy

Last Updated: April 14, 2026

This Privacy Policy explains how Muzix collects, uses, and protects information gathered from Discord.

1. Information We Collect

  • Discord IDs: Server (Guild) IDs, Voice/Text Channel IDs, and User IDs.
  • No-Prefix User Data: If granted "no-prefix" privileges, we store your specific Discord User ID in our database.
  • Voice State Data: Information regarding user presence in voice channels.
  • Message Content: If communicating via text commands, the bot reads the message to execute your request.

2. How We Use Your Information

Data is strictly used to operate the bot. User IDs saved for "no-prefix" status are checked against incoming messages. Voice state data and User IDs track requests and facilitate features like auto-resume and node relocation. Server and Voice Channel IDs are required to establish audio connections through our Lavalink nodes.

3. Data Storage and Retention

  • Persistent Data: Data necessary for continuous features (like your User ID for "no-prefix" privileges) is stored securely until revoked or deletion is requested.
  • Temporary Data: Active music queues and voice channel states are held in memory and cleared once playback ends.

4. Your Rights

Users and server administrators have the right to request the deletion of any persistent data associated with them. To request removal, join our Support Server.
